# Итерации обучения MarioJev

Все прогоны — на ПК (Ryzen 5 7500F, GTX 1050 Ti, WSL Ubuntu 24.04), 23.09.2026.
Уровни: процедурные (`ai/levelgen.py`) + train-уровни `goombas`, `pipes`.
Отложенные (test) уровни — `1-1`, `warmup`, `skybridge`, `treasury`: их модель не видит ни
при обучении, ни при выборе чекпойнта (кроме итерации 1 — см. ниже).

Валидация — 8 процедурных уровней на фиксированных сидах + train-уровни, по 3 прогона с
сэмплированием. Шум одной точки — ±300–500 очков, поэтому сравнения — по нескольким точкам.

## Что проверено и работает

- Прогон одной и той же модели через среду обучения и через контроллер живой игры совпадает
  кадр в кадр (722 кадра, те же очки и причина смерти).
- Мир детерминирован и одинаков на macOS и Linux: 1-1 ботом — 3 980 очков, 1 952 кадра на обоих.
- Интерфейс: 36/36 проверок `tools/check_ui.py`, включая отрисовку всех экранов невидимым окном.

## Как продолжать

Следующая цель — «Небесный мост» и «Сокровищница» (длинные пропасти с парящими платформами). Трудные
процедурные уровни (`it5`) сами этого не дали: генератору нужен чанк «цепочка узких платформ над
пропастью 8+ тайлов», и в обучение стоит добавить больше таких уровней.

```bash
# на ПК (WSL), из корня репозитория; обновление весов на GPU — окружение .venv-cuda
.venv-cuda/bin/python -m ai.train --device cuda --init ai/models/it4a_best.pt --name it6 \
    --steps 2000000 --envs 5 --gamma 0.97 --lr 7e-4 --max-grad-norm 2.0 \
    --ent 0.02 --ent-final 0.005 --difficulty-start 0.6 --mix 0.7
.venv-cuda/bin/python -m ai.calibrate --model ai/models/it6_best.pt --out ai/models/it6_final.pt
.venv-cuda/bin/python -m tools.tournament --model ai/models/it6_final.pt --runs 3
```
