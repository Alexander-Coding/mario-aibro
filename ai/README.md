# ai/ — нейросеть MarioJev

Модель решений в духе Jev: она не пишет текст, а отвечает на типизированные
вопросы вероятностями. Учится играть так, чтобы набрать как можно больше
очков, — по правилам игры побеждает не тот, кто прошёл, а тот, кто набрал
больше.

## Как это устроено

```
GameWorld (core/world.py) ─► FeatureBuilder (ai/features.py) ─► MarioJev (ai/model.py)
   логика уровня без окна        типизированное состояние          трансформер, 0.33 М параметров
                                  карта 9×16×24 + враги + игрок      choice / noul / score
```

- **Мир один на всех.** Живая игра (`game.py` через `ui/session.py`) и обучение крутят один и
  тот же `GameWorld` с фиксированным шагом 1/60 с. Модель в окне видит ровно то, на чём училась
  (проверено: прогон через среду и через контроллер игры совпадает кадр в кадр).
- **Решение 15 раз в секунду** (раз в 4 кадра), прыжок — одно нажатие.
- **Вход:** карта тайлов вокруг Марио (стены, «?» с числом ударов, монеты, враги, флагшток, замок,
  трубы в секретные комнаты и выход из комнаты), до 8 ближайших врагов с точными координатами и
  скоростью, вектор игрока (скорость, опора, жизни, время, где флагшток и как высоко до его верха,
  в комнате ли, стоит ли на трубе-входе, где ближайшая непосещённая труба).
- **Выход — три вопроса, как у Jev:**
  - `choice` — какое нажатие: стоять / вправо / влево / прыжок / вправо+прыжок / влево+прыжок / вниз;
  - `noul` — вероятность погибнуть в ближайшие 2 секунды;
  - `score` — сколько очков ещё будет набрано до конца уровня (диапазоны).
- **Обучение в два этапа:** PPO на награде = очки игры дал уверенного спидраннера (`it4a`); итоговая
  модель учится подражанием учителю (`ai/teacher.py`: `it4a` + правила сбора) и DAgger
  (`ai/imitate.py`). `noul`, `score` и температуры калибруются после обучения на полных эпизодах,
  сыгранных так, как модель играет в игре (`ai/calibrate.py`), чтобы «10 %» значило 10 %.

## Награда

| Что | Награда |
|---|---|
| Очки игры (монета, блок, враг, флаг, бонус за время) | очки / 100 |
| Продвижение (`--reward progress`, по умолчанию) | 30 · Δ(лучший X) / длина уровня — только за новый максимум, за уровень ровно 30 |
| Потеря жизни | −3 |
| Смерть | −10 (и не будет ни флага, ни бонуса за время) |

Режим `--reward collect` (итерации 6–9): подсказка за продвижение слабее (10 за уровень), бонус 3 за
первый вход в тайник, по желанию — штраф за оставленное позади (`--miss-penalty`) и тренировочные арены
(`--drill`). Выводы — в `docs/ITERATIONS.md`: штраф больше подсказки за продвижение делает движение
вперёд невыгодным, а навык «встать под блок и прыгать» PPO от спидраннера не нашёл.

γ = 0.97. На первых итерациях была потенциальная подсказка γ·Φ(s′) − Φ(s) (`--reward potential`) при
γ = 0.995: она не меняет лучшую стратегию, но на эпизодах в ~340 решений давала шумные преимущества,
а при меньшем γ — дрейф −(1−γ)·Φ за шаг. История и цифры — в `docs/ITERATIONS.md`.

## Уровни

- **Процедурные** (`ai/levelgen.py`) — новый уровень каждый эпизод, сложность растёт по учебному плану.
  Заучить их нельзя, приходится уметь играть.
- **train** из `maps/levels.json` — участвуют в обучении.
- **test** из `maps/levels.json` (в том числе 1-1) — отложенные: модель их не видит ни при обучении,
  ни при выборе лучшего чекпойнта. На них проверяется, что она умеет играть, а не помнит уровень.

## Команды

```bash
# обучение на ПК с видеокартой (окружение .venv-cuda: torch 2.8 cu126 — последняя сборка с Pascal/GTX 1050 Ti)
.venv-cuda/bin/python -m ai.train --device cuda --name it6 --steps 2000000 --envs 5 \
    --gamma 0.97 --lr 7e-4 --max-grad-norm 2.0 --ent 0.02 --ent-final 0.005 --init ai/models/it4a_best.pt

# подражание учителю + DAgger (итоговая модель; подробно — README в корне)
.venv/bin/python -m ai.imitate collect --episodes 1500 --out ai/runs/demos
.venv/bin/python -m ai.imitate train --data ai/runs/demos --init ai/models/it4a_best.pt --name bcA
.venv/bin/python -m ai.imitate collect --student ai/models/bcA_best.pt --sample --beta 0.2 --out ai/runs/dagger1

# калибровка ответов noul/score (эпизоды — в том режиме, в котором модель будет играть: --play sample)
.venv/bin/python -m ai.calibrate --model ai/models/bcA_best.pt --out ai/models/my_final.pt --play sample

# турнир: все участники на всех уровнях, итог по сумме очков (+ --laya для открытой альтернативы Jev)
.venv/bin/python -m tools.tournament --model ai/models/mariojev_final.pt --teacher ai/models/it4a_best.pt --runs 5

# посмотреть в игре: меню → «ИИ» (модель по умолчанию — самый свежий *_final.pt)
.venv/bin/python main.py
```

Итоговая модель — `ai/models/mariojev_final.pt` (играет сэмплом): 64 708 очков за 6 уровней против
47 740 у прошлой версии-спидраннера; на отложенных уровнях 37 004 против 23 340; ударов по «?» 83 из 220
(было 9), тайников 4.4 из 6 (было 0).

## Файлы

| Файл | Что внутри |
|---|---|
| `features.py` | Типизированное состояние из `GameWorld`, действия |
| `model.py` | MarioJev: патчи карты + токены врагов и игрока → трансформер → 4 головы |
| `env.py` | Gymnasium-среда: 4 кадра на шаг, награда, источник уровней |
| `train.py` | PPO, учебный план сложности, валидация, чекпойнты |
| `calibrate.py` | Голова `score`, температуры, ECE до и после |
| `decide.py` | API решений как у Jev: `choice` / `noul` / `score` с вероятностями |
| `agent.py` | Контроллер для живой игры и турнира |
| `teacher.py` | Учитель: модель ведёт по уровню, правила собирают блоки «?», монеты, тайники |
| `imitate.py` | Подражание учителю и DAgger: сбор примеров, обучение ученика |
| `laya_agent.py` | Открытая альтернатива Jev (Laya) как игрок без дообучения — для сравнения |
| `levelgen.py` | Процедурный генератор уровней |
